# Invoice Follow-Up Sprint validation site

This is a single-page, zero-dependency validation site for the first commercial experiment. It does not collect visitor data or payment details. The local calculator runs entirely in the visitor's browser.

The public page is intentionally limited to a founding seven-day pilot for routine, undisputed Australian B2B invoices. Research and internal operating records are not part of the deployed site.

Public URL: https://spancut.github.io/invoice-recovery-sprint/

Deployment: GitHub Pages from `dist/` via `.github/workflows/pages.yml`. The site uses no paid services, remote runtime dependencies, analytics, cookies, public form, or payment collection.
